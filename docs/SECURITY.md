## Перевірено, проблем нема
- Протокол синхронізації: AES-256-GCM, ключі на сесію з двох nonce, окремі для напрямків, лічильник проти повторів; код ~79 біт.
- До автентифікації розбирається лише nonce; JSON — тільки після розшифрування.
- `allowBackup=false`, release не debuggable, R8.
- Залежності: 174 бібліотеки, OSV — 0 відомих вразливостей (перевіряється в CI на кожну збірку, `osv.txt` у гілці `ci-log`).

## Лишається (рішення за власником)
1. **Публічний репозиторій** — код, підписані APK і скріни в `ci-log` доступні всім. Рекомендовано зробити приватним.
2. **Дані на телефоні не зашифровані** (SharedPreferences: вильоти, координати, маршрути). При захопленні телефону — все читається. Варіант: шифрування + PIN/біометрія + «тривожне» очищення.
3. **Тип сервісу `_kapibara._tcp`** лишився (сумісність зі старими версіями) — сам по собі впізнаваний у мережі.
4. **Тайли ArcGIS з інтернету** розкривають район перегляду карти провайдеру тайлів. Варіант: офлайн-кеш/MBTiles.
5. Будь-хто з кодом хаба може змінити/скинути спільні дані (за задумом). Код не передавати поза групою.
6. Служба спецможливостей — потужний дозвіл; обмежена пакетом DJI Pilot 2.
